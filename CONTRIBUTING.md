# Contributing

Thank you for your interest in contributing to Base Mini-App!

## Getting started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/base-miniapp`
3. Make your changes in a new branch: `git checkout -b feat/my-feature`
4. Open a pull request against `main`

## Guidelines

- Keep changes focused — one feature or fix per PR
- Follow the existing code style (plain vanilla JS, no framework)
- Test in both Base Mainnet and Base Sepolia before submitting
- Update README.md if you add user-facing functionality

## Reporting bugs

Open a GitHub issue with:
- Browser and MetaMask version
- Steps to reproduce
- Expected vs actual behaviour
